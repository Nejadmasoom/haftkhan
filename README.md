# هفت‌خوانِ حرکت

بازیِ حرکتی برای «کتاب کار حرکت و بازی، اول دبستان» (کد ۱۰۹۱، اجرای آزمایشی).
دوازده درسِ کتاب در هفت خوان چیده شده؛ یوزی، توله‌یوزِ ایرانی، همسفرِ کودک است و با هر روزِ تمرین بزرگ‌تر می‌شود.

## محتوا

| مسیر | چیست |
|---|---|
| `prototype/index.html` | پیش‌نمایشِ تعاملیِ رابط: نقشه، خوانِ تعادل، تمرین، پاداش، بازیِ خانوادگی، بخش والدین. با باز کردنِ فایل در مرورگر اجرا می‌شود. |
| `prototype/img/` | نسخهٔ سبکِ (۵۱۲ پیکسل، WebP) تصویرهایی که پیش‌نمایش استفاده می‌کند |
| `assets/sheets/` | برگه‌های خامِ کاراکترها، همان‌طور که از تصویرساز آمده‌اند |
| `tools/` | ابزارِ بریدنِ برگه‌ها و هم‌ترازکردنِ کادرهای حرکت |
| `docs/character-prompts.md` | پرامپت‌های ساختِ هر برگه |
| `docs/characters.md` | فهرستِ کاراکترها و حالت‌هایی که باید کشیده شوند |
| `assets/characters/` | محلِ تصویرِ کاراکترها |
| `.claude/skills/ui-ux-pro-max/` | اسکیلِ طراحیِ رابط ([منبع](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)) |

## چیدمانِ درس‌ها در خوان‌ها

| خوان | درس‌های کتاب |
|---|---|
| ۱ بیدارِ بدن | ۱ درک حرکت · ۲ وضعیت‌های بدنی درست |
| ۲ دشتِ تیزپاها | ۳ راه رفتن، دویدن، پریدن · ۴ بدن قوی |
| ۳ پلِ لرزان | ۵ تعادل · ۶ زندگی فعال |
| ۴ بیشهٔ بید | ۷ بدن نرم · ۸ هماهنگی |
| ۵ درهٔ پرتاب | ۹ پرتاب و دریافت · ۱۰ کار با پا |
| ۶ چشمهٔ دل | ۱۱ قلب قوی |
| ۷ جشنِ سرزمین | ۱۲ بازی‌های بومی‌محلی |

## یادداشت

فایلِ PDF کتاب در مخزن نیست (۲۵ مگابایت و متعلق به سازمان پژوهش و برنامه‌ریزی آموزشی). برای کار، آن را در `book/` بگذارید؛ این پوشه از git بیرون است.
