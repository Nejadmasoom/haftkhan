# گذاشتنِ بازی روی یک هاستِ ساده

- بسته: `bash tools/host-package.sh haftkhan-host.zip` — فقط فایل‌های لازم، به‌اضافهٔ `.htaccess` (https، نوعِ فایل‌های موتورِ دوربین، فشرده‌سازی، کش).
- صداها در بسته با ۶۴ کیلوبیت تک‌کاناله (به‌جای ۹۶) ذخیره می‌شوند تا بسته زیرِ ۳۰ مگابایت بماند؛ برای گفتار فرقی شنیده نمی‌شود.
- کنار گذاشته شده: `pose/model.js` و `pose/wasm.js` (۲۰ مگابایت؛ فقط برای باز کردن با دوبار-کلیک روی کامپیوتر لازم‌اند — روی سایت فایل‌های اصلیِ `.wasm` و `.task` بارگذاری می‌شوند) و `digits.png`.
- راهنمای فارسیِ گام‌به‌گام: `host-guide-fa.pdf` (منبع: `guide.html`؛ تصویرها و قلم‌ها را کنارش بگذارید و با Chromium چاپ کنید).
- آزموده: بسته روی یک سرورِ http محلی باز شد، موتورِ دوربین در ۱٫۲ ثانیه آماده شد و هیچ درخواستی به نسخه‌های پشتیبان نرفت.
