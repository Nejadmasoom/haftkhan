# انتشار بازی روی GitHub Pages

بازی یک وب‌سایتِ ساده است؛ نسخهٔ قابلِ بازی‌اش روی شاخهٔ `gh-pages` است (بدونِ محدودیتِ تعدادِ فایل و بدونِ لینکِ ۶۰ دقیقه‌ای).

## یک بار: روشن کردن (دو کلیک)
۱. در GitHub به مخزن بروید: **Settings ← Pages**.
۲. زیرِ **Build and deployment**، «Source» را روی **Deploy from a branch** بگذارید، شاخه را **gh-pages** و پوشه را **/ (root)** انتخاب کنید و **Save** بزنید.
۳. بعد از یکی دو دقیقه آدرس همین‌جا نشان داده می‌شود: **https://nejadmasoom.github.io/haftkhan/**

## هر بار که بازی عوض شد
از ریشهٔ مخزن: `bash tools/publish-pages.sh` (از `prototype/` شاخهٔ `main` کپی می‌کند و می‌فرستد). یا به Claude بگویید «صفحه را به‌روز کن».

## یادداشت
- نسخهٔ Claude artifact بیشتر از ۵۱۱ فایل نمی‌گیرد؛ نسخهٔ کامل فقط این‌جا و در زیپ است.
- دوربین فقط روی HTTPS کار می‌کند؛ GitHub Pages همیشه HTTPS است.
