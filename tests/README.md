# آزمون‌های خودکار

هر آزمون بازی را در Chromium باز می‌کند (Playwright) و یک بدنِ شبیه‌سازی‌شده جلوی دوربین می‌گذارد:
یک بار بی‌حرکت با لرزشِ دوربین (باید صفر بشمارد) و یک بار با حرکتِ درستِ همان بازی (باید بشمارد).

| فایل | چه می‌سنجد |
|---|---|
| `audit.mjs` | همهٔ صفحه‌ها در سه اندازه: اسکرولِ افقی، بیرون‌زدگی، دکمهٔ زیرِ ۴۴px، نوشتهٔ زیرِ ۱۲px، عکسِ خراب، خطا؛ و عکسِ هر صفحه در `aud/` |
| `tgames.mjs` | بازی‌های شمارشیِ منزل‌های ۱ تا ۴ |
| `tstory.mjs` | کارهای دوربینیِ قصه‌ها |
| `tl5.mjs` | منزلِ ۵ و رکوردِ لک‌لک، از راهِ حلقهٔ واقعیِ دوربین |
| `tfam.mjs` | بازی‌های خانوادگی (اوستا، صندلی‌بازی، دستمال‌بازی) |
| `tarena3.mjs` | تپه‌نوردی و دیوارِ شکل‌ها |

اجرا از پوشه‌ای که ویدئوی ساختگیِ دوربین در آن است:

- `tfree.mjs` — «همیشه می‌شود بیشتر بازی کرد»: هر درس در روزِ بازی‌شده، روزِ استراحت و بعد از سه مشعل.
- `tl678.mjs` — درس‌های ۶ تا ۸: حرکت‌های ماندنی و بدن‌کوبه با دوربین، بازی‌های لمسی، و بازی‌های خانوادگی و صفحه‌های ستارهٔ تازه.

```
ffmpeg -f lavfi -i color=c=gray:s=640x480:d=2 -pix_fmt yuv420p blank.y4m
cp blank.y4m portrait.y4m
mkdir -p aud && node /home/user/haftkhan/tests/tgames.mjs
```
